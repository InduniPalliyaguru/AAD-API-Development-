This repository contains lab practicals, architecture patterns, and backend API implementations developed during the **Advanced API Development (AAD)** module. All projects are built using the **Spring Boot** framework, mapping clean business structures to relational databases and testing via Postman client.

---

### 🗺️ Architecture Overview & Concepts Covered

Throughout these lab sessions, the implementation focused heavily on building standard **RESTful Web Services** following a **Layered Architecture Pattern** (Controller -> Service -> Repository).

Key technical concepts explored:
* **Object-Relational Mapping (ORM):** Managing automated schema generations and associations.
* **REST Constraints:** Designing semantic web end-points utilizing appropriate HTTP verbs and structured response entities.
* **Data Filtering:** Querying backend datasets dynamically using conditional repository mappings.
